# Game Night Scores

Log final scores from board game nights. Your history syncs across iPhone, iPad, Mac and PC,
and the app works offline, syncing when you're back online.

Open it at https://jacksontann14.github.io/scorekeeper/

## Install
- iPhone/iPad: open the link in Safari > Share > Add to Home Screen. Sign in inside the
  installed app, not in Safari (they keep separate logins).
- Mac: Safari > File > Add to Dock, or the install icon in Chrome/Edge's address bar.
- PC: the install icon in Chrome/Edge's address bar.

Sign in once per device and it stays signed in.

## Log a session
1. Tap **New session**.
2. Type or pick the game. A new name is added to your games automatically.
3. Tick the expansions you played with, or add a new one.
4. Turn on **Lowest score wins** for games like golf. It's remembered for that game.
5. Choose who played (or add a new player), then enter each final score.
   Use **±** for negative scores.
6. Tap **Save session**.

Tap any session card to edit or delete it. Use the filter at the top to show one game.

## Games
Add games and their expansions on the **Games** tab. Use **+** to add an expansion,
the pencil to rename and the bin to delete. A game can only be deleted once no sessions use it.
Deleting an expansion removes it from past sessions but keeps their scores.

## Players
Add, rename or delete players on the **Players** tab. Deleting a player removes their scores
from past sessions, and deletes any session left with no one in it.

## Stats
The **Stats** tab shows each player's games played, wins and win rate, and for each game
how often it's been played, who has the most wins and the best score.

## Backups
On the **Stats** tab:
- **Export backup** saves a JSON file (share sheet on phone, download on computer).
- **Import backup** loads one. Choose merge to add to what's there, or replace to overwrite everything.

The account section also shows whether everything has synced.
