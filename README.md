# Game Night Scores

Log final scores from board game nights. Your history syncs across iPhone, iPad, Mac and PC,
and the app works offline, syncing when you're back online.

Open it at https://jacksontann14.github.io/scorekeeper/

## Install
- iPhone/iPad: open the link in Safari > Share > Add to Home Screen. Sign in inside the
  installed app, not in Safari (they keep separate logins).
- Mac: Safari > File > Add to Dock, or the install icon in Chrome/Edge's address bar.
- PC: the install icon in Chrome/Edge's address bar.

Sign in once per device and it stays signed in.

## Log a session
1. Tap **New session**.
2. Type or pick the game. A new name is added to your games automatically.
3. Tick the expansions you played with, or add a new one.
4. For co-op games, turn on **Co-op game** and pick **We won** or **We lost**.
   Otherwise turn on **Lowest score wins** if it applies. Both are remembered for that game.
5. Choose who played (or add a new player), then enter each final score.
   Use **±** for negative scores.
6. If the game tracks factions or characters, type each player's under their name.
7. Optionally pick **Who went first?**
8. Tap **Save session**.

Tap any session card to edit or delete it. Use the filter at the top to show one game.

## Games
On the **Games** tab, tap **New game** or tap a game to edit it. In the game sheet you can set:
- name, player count and play time
- **Co-op**, **Lowest score wins**, and **Track factions or characters**
- expansions: add, rename or remove

A game can only be deleted once no sessions use it. Removing an expansion takes it off past
sessions but keeps their scores.

**What should we play?** Use the filters at the top of the Games tab to show games that fit
your player count and the time you have. Sort by **Least recently played** to bring out games
that haven't been played in a while, or ever. Games need a player count and play time to match these filters.

## Players
Add, rename or delete players on the **Players** tab. Deleting a player removes their scores
from past sessions, and deletes any session left with no one in it.

## Stats
The **Stats** tab shows:
- **Players**: played, wins, win rate, current and best win streak (competitive games only)
- **Games**: times played, most wins (or the team's record for co-op games), best score
- **Head to head**: each player's wins and losses against each other player
- **Factions and characters**: how often each one has won
- **Expansions**: average winning score (or co-op win rate) with and without each expansion
- **Going first**: how often the first player won, against what you'd expect by chance

Tables appear once there's data for them.

## Backups
On the **Stats** tab:
- **Export backup** saves a JSON file (share sheet on phone, download on computer).
- **Import backup** loads one. Choose merge to add to what's there, or replace to overwrite everything.

The account section also shows whether everything has synced.
